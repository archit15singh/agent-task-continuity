# Naming and README decisions

| Guidance | How Worktree Ledger applies it |
| --- | --- |
| Choose a memorable name that explains the project and check for nearby names in the ecosystem. [Open Source Guides](https://opensource.guide/starting-a-project/) | Worktree names the recovered Git workspace. Ledger names the SQLite record of task authority, verification, and external writes. Exact-name checks found no matching public GitHub repository or package at the matching PyPI and npm endpoints. Worktree Handoff already appeared as a project name and as a coding-agent skill. |
| Answer what the project does, why someone would use it, how to start, and where to get help. Use branch-relative links for files in the repository. [GitHub README guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes) | The landing page explains when manual Git is enough, demonstrates a local handoff, and links to operating instructions, evidence, and issues. |
| Provide runnable artifact commands, describe how to verify results, and identify dependencies or credentials for reproductions. [ACM SIGSIM artifact evaluation](https://sigsim.acm.org/conf/pads/2026/blog/artifact-evaluation/) | The README distinguishes checking archived evidence from rerunning the live study. The evidence guide lists run requirements and the paper defines what counts as passing. |
| Publish machine-readable citation metadata and link the paper readers should cite. [Citation File Format](https://citation-file-format.github.io/) · [GitHub citation guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-citation-files) | The repository has a root citation file that points to the report under its existing title. Historical evidence still points at the original commits. |
| Update canonical URLs and the Git remote after a rename. Keep the previous name available for GitHub's redirects. [GitHub rename guidance](https://docs.github.com/en/repositories/creating-and-managing-repositories/renaming-a-repository) | The GitHub name follows the project brand. The Python distribution, `continuity` command, and stored task format retain their identifiers so existing installs and checkpoints carry forward. |
